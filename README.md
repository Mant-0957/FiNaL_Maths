# Dataset

The dataset used in this project is:

`employee_performance.csv`

### Dataset Features

* Employee_ID
* Department
* Age
* Salary
* Projects_Completed
* Working_Hours
* Performance_Score
* Promotion_Status

The dataset contains 5000 rows and has no null values.

# Project Objectives

The main objectives of this project are:

* Understand measures of central tendency
* Analyze variance and standard deviation
* Perform probability calculations
* Study distributions and visualizations
* Apply linear algebra concepts using employee vectors
* Generate insights from employee performance data
